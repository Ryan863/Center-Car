# Center Car - Lavação Automotiva

Landing page editorial cinematográfica de altíssimo impacto e conversão desenvolvida para a **Center Car - Lavação Automotiva** (Rio do Sul - SC), inspirada no estilo estúdio dark **Max Color**.

## 🏎️ Tecnologias Utilizadas

- **Framework:** Next.js 16 (App Router)
- **Linguagem:** TypeScript
- **Estilização:** Tailwind CSS v4 & Vanilla CSS
- **Animações:** GSAP 3 com ScrollTrigger & `@gsap/react`
- **Ícones:** Lucide React
- **Tipografia:** Outfit & Plus Jakarta Sans via `next/font/google`
- **SEO & Structured Data:** Schema.org `LocalBusiness` / `AutoWash`, OpenGraph & Twitter Cards

## 🚀 Como Executar Localmente

```bash
# Clone o repositório
git clone https://github.com/Ryan863/Center-Car.git

# Acesse o diretório
cd Center-Car

# Instale as dependências
npm install

# Inicie o servidor de desenvolvimento
npm run dev
```

Acesse [http://localhost:3000](http://localhost:3000) no seu navegador.

## 📦 Build para Produção

```bash
npm run build
npm run start
```
